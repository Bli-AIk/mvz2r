# MC大战僵尸2:幻想曲

| [English](readme_en.md) | 简体中文 |
| :---------------------: | :------: |

**MC大战僵尸2:幻想曲** 是MVZ2的一个非官方实验性分支。该分支的目的是尽量在不直接修改MVZ2原作内容的基础上,制作一条灵感源自 rougelite 玩法、《美食大战老鼠》网游、且关卡流程尽可能贴近 东方Project 系列正作 (整数作) 的重构想主线，同时带来一系列的 QoL 增强。

我们尊重 MVZ2 原作的一切著作权。本仓库是使用 Odin 实现的完整重写,不使用原 GPLv3 源码,并完全面向开源社区。MVZ2 原作及其相关素材 (程序、美术、音乐等) 均遵循 GPLv3,权益归各自权利人所有。我们自行编写的代码以 Zlib 许可证授权——这是一份极为宽松的许可：任何人都可以自由使用、修改、再分发，只需保留版权声明与免责声明，且不得声称原始软件出自你手。任何人可以提交 Issue、PR，展开讨论，对该项目的发展提出建议意见想法。
