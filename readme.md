# MC大战僵尸2:幻想曲

| [English](readme_en.md) | 简体中文 |
| :---------------------: | :------: |

**MC大战僵尸2:幻想曲** 是一款基于 MVZ2（Minecraft Vs Zombies 2）的非官方同人游戏，与 MVZ2 官方团队没有任何隶属关系。

项目采用开放的模组架构：本体的目标是成为一套用 Odin 实现的引擎框架，各类内容以 mod 的形式作为子模块接入——MVZ2 原作内容是一个 mod，幻想曲本身也是一个 mod。我们希望这套架构足够开放，任何人都能编写自己的内容 mod。（项目目前处于早期阶段。）

幻想曲内容在尽量不直接沿用 MVZ2 原作内容的基础上，重新构建一条灵感源自 roguelite 玩法、《美食大战老鼠》网游、且关卡流程尽可能贴近 东方Project 系列正作（整数作）的主线，同时带来一系列的 QoL 增强。

我们尊重 MVZ2 原作的一切著作权。本体使用 Odin 独立实现，不使用 MVZ2 原作的 GPLv3 源码；除复刻 MVZ2 原作内容的 mod 之外，我们自行编写的代码以 Zlib 许可证授权——这是一份极为宽松的许可：任何人都可以自由使用、修改、再分发，只需保留版权声明与免责声明，且不得声称原始软件出自你手。复刻 MVZ2 原作内容的 mod 复用原作素材（美术、音乐等），因此该 mod 保持 GPLv3 授权；MVZ2 原作及其相关素材（程序、美术、音乐等）均遵循 GPLv3，权益归各自权利人所有。任何人可以提交 Issue、PR，展开讨论，对该项目的发展提出建议意见想法。
