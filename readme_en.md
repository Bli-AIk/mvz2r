# Minecraft Vs Zombies 2: Reverie

| English | [简体中文](readme.md) |
|:---------------------:|:--------------------:|

**Minecraft Vs Zombies 2: Reverie** is an unofficial fan game inspired by MVZ2, and is not affiliated with the MVZ2 team in any way.

The project uses an open mod architecture: the goal is for the core to become an engine framework implemented in Odin, with all content provided as mods plugged in as submodules — the original MVZ2 content is one mod, and Reverie itself is another. We want this architecture to be open enough that anyone can write their own content mods. (The project is still at an early stage.)

The Reverie content aims to create a reimagined main story line inspired by roguelite gameplay, the web game "Foodstuff vs. Mice", and the level progression of the official Touhou Project series (integer-numbered titles), while trying to avoid reusing the original MVZ2 content as much as possible. It also aims to bring a series of QoL (Quality of Life) enhancements.

We respect all copyrights of the original MVZ2. The core is an independent implementation in Odin and does not use the original GPLv3 source code; except for the mod that recreates the original MVZ2 content, our own code is licensed under the Zlib license — a highly permissive license that allows anyone to freely use, modify, and redistribute it, as long as the copyright notice and disclaimer are preserved and you do not claim to have written the original software. The mod that recreates the original MVZ2 content reuses the original assets (art, music, etc.) and is therefore released under GPLv3; the original MVZ2 project and its related assets (code, art, music, etc.) are licensed under GPLv3, and all rights belong to their respective owners. Anyone is welcome to submit Issues, PRs, start discussions, and provide suggestions for the development of this project.
