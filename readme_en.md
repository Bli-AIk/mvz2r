# Minecraft Vs Zombies 2: Reverie

| English | [简体中文](readme.md) |
|:---------------------:|:--------------------:|

**Minecraft Vs Zombies 2: Reverie** is an unofficial, experimental branch of MVZ2. The goal of this branch is to create a "reimagin" main story line inspired by roguelite gameplay, the web game "Foodstuff vs. Mice", and the level progression of the official Touhou Project series (integer-numbered titles), while trying to avoid direct modification of the original MVZ2 content as much as possible. It also aims to bring a series of QoL (Quality of Life) enhancements.
